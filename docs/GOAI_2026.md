# GOAI 2026 — Agent Infra track mapping

This repository is the runnable companion to the Cogram preliminary design
submission. It exists so a reviewer can check claims against code instead of
slides.

| Handbook requirement (§1.3) | Where it is satisfied |
|---|---|
| Multi-agent collaboration on a complex task | A1 triage → A2 memory → A3 verifier → human gate |
| Skill reusability / engineering encapsulation | `cogram.keyword_recall` + `cogram.evidence_bind` (`cogram-goai tools`) |
| Context management + execution evidence | cited `context` packet, evidence map, JSONL trace, `replay` |
| Security, approval, rollback, audit | path denylist; pending-if-no-approver; `rollback` keeps the row; append-only trace |
| Openness / long-term growth | Apache-2.0, zero deps, public GitHub, documented SCOPE |

Identity of the three agents: [AGENT_IDENTITY.md](AGENT_IDENTITY.md).

## Deliberate omissions

Per [SCOPE.md](SCOPE.md), this entry contains no vector retrieval, no graph
memory or decay mechanics, no line-level source routing, no private benchmarks,
no cloud auth, and no licensing. Those belong to a separate product effort and
are not part of this submission.

## Reproducing the demo

```bash
pip install -e .
python -m unittest discover tests -v
cogram-goai demo --auto-approve --trace run.jsonl
cogram-goai replay --trace run.jsonl
cogram-goai tools
```

The trace is the evidence artifact; every claim in the demo corresponds to one
line in it.
