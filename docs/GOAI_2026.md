# GOAI 2026 — Agent Infra track mapping

This repository is the runnable companion to the Cogram preliminary design.
A reviewer can check claims against code instead of slides.

Official topic: **Direction 3 — End-to-end Software Development Collaboration**
([track page](https://www.goaihz.com/en/tracks/agent-infra), Beijing Time).

| Official review dimension | Weight | Where it is |
|---|---|---|
| Scenario value / replicability | 25% | Software-incident loop; demo issue is a large-upload timeout; same pipeline on any issue text + note JSON |
| Multi-agent closed loop | 25% | A1 triage → A2 memory → A3 verifier → human gate → capture / rollback. Agents never call each other |
| Skill engineering | 25% | five contracts in `cogram-goai tools` (I/O + failure explicit) |
| Engineering / trace / security | 20% | hash-chained JSONL, `verify-trace --complete`, path_guard, redact, pending-if-no-approver |
| Open-source | 5% | Apache-2.0, zero runtime deps, `docs/SCOPE.md` |

AgentTeams is the design baseline, not a product name to drop. Mapping:

| Baseline capability | This repo |
|---|---|
| Role orchestration | `docs/AGENT_IDENTITY.md` |
| Task decomposition | A1 budgeted subtasks |
| Context passing | cited packet; `high` only auto-injects; conflict empties it |
| Collaborative execution | A2 → A3 → human → A2 |
| State tracking | JSONL `prev_hash` / `hash` |

Identity of the three agents: [AGENT_IDENTITY.md](AGENT_IDENTITY.md).

## Deliberate omissions

Per [SCOPE.md](SCOPE.md), this entry contains no vector retrieval, no graph
memory or decay mechanics, no line-level source routing, no private benchmarks,
no cloud auth, and no licensing. Those belong to a separate product effort and
are not part of this submission.

## Reproducing the demo

```bash
pip install -e .
python -m unittest discover tests -v
cogram-goai demo --auto-approve --trace run.jsonl
cogram-goai demo --conflict --auto-approve --no-capture
cogram-goai replay --trace run.jsonl
cogram-goai verify-trace --trace run.jsonl --complete
cogram-goai tools
```

The trace is the evidence artifact; every claim in the demo corresponds to one
line in it.
