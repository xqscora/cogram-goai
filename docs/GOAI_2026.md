# GOAI 2026 — Agent Infra track mapping

This repository is the runnable companion to the Cogram preliminary design
submission. It exists so a reviewer can check claims against code instead of
slides.

| Handbook requirement | Where it is satisfied |
|---|---|
| Multi-agent role orchestration | `src/cogram_goai/agents/`, three roles with explicit decision boundaries ([identity list](AGENT_IDENTITY.md)) |
| Task decomposition | `agents/triage.py` — 2–3 subtasks with step budgets |
| Context passing | `agents/memory.py` → skill result consumed by the verifier and the human |
| Mandatory skill, fully specified | `cogram.keyword_recall` ([contract](SKILL_keyword_recall.md), printable via `cogram-goai contract`) |
| Tool calling | Local file read/write through `NoteStore`; contract lists the MCP-equivalent tool |
| Verification | `agents/verifier.py` — every subtask must carry evidence |
| Observability | Append-only JSONL trace, one line per event ([event table](ARCHITECTURE.md#event-vocabulary-in-the-trace)) |
| Memory storage | Plain JSON note store, keyword recall, write-back on approval |
| Human in the loop | Structural approval gate; no approver means no write |
| Closed loop | `cogram-goai demo --auto-approve --trace run.jsonl` runs input → decompose → recall → verify → approve → capture |

## Deliberate omissions

Per [SCOPE.md](SCOPE.md), this entry contains no vector retrieval, no graph
memory or decay mechanics, no line-level source routing, no private benchmarks,
no cloud auth, and no licensing. Those belong to a separate product effort and
are not part of this submission. If a reviewer asks for numbers on a private
evaluation set: there are none here, on purpose.

## Reproducing the demo

```bash
pip install -e .
python -m unittest discover tests -v          # 46 tests
cogram-goai demo --auto-approve --trace run.jsonl
cat run.jsonl
```

The trace is the evidence artifact; every claim in the demo script corresponds
to one line in it.
